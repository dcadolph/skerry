Skerry

Markdown notes that live in your own files, sealed with a key only you hold.

Free and open source. Still a work in progress.

Encryption you can check

Set a passphrase once, then seal any note from its menu. A security claim without a threat model is marketing, so the threat model says what Skerry protects, what it cannot, and how the cryptography works. The scheme is in FORMAT.md and the code is open.

AES-256-GCM per note

A random 256-bit master key seals each note, with ChaCha20-Poly1305 as a choice. The master key is wrapped by a key stretched from your passphrase with Argon2id. A modified note fails to open instead of opening wrong.

Nothing left in the clear

A sealed note becomes an opaque <id>.md file. Its title, tags, dates, and body are all ciphertext, and it stays out of the search index.

Decoy and self-destruct

An optional decoy passphrase opens a separate, innocent library from the same prompt. Another option erases this device's vault key after repeated wrong guesses.

Sealed before it leaves

Backups and sync objects are encrypted before upload, so your own storage only ever holds ciphertext under opaque names.

Keychain and Touch ID

The passphrase is held in the Keychain and released only after you authenticate. A one-time recovery code is a second way in.

Locks that close

Per-note locks, auto-lock timers, and a privacy cover in the app switcher. Text copied from an encrypted note leaves the clipboard after a minute.

Cheap passphrase changes

Changing your passphrase re-wraps the master key, so no note has to be re-encrypted.

Checked against the spec

The Argon2id implementation is gated on the RFC 9106 test vectors, and the cryptographic core ships with its tests.

Your notes are just files

A library is any folder you pick. Notes are .md files, folders are folders, and attachments live in assets/. The only thing Skerry adds is a .skerry/ cache for the search index, and it rebuilds if you delete it. Delete the app and your notes are still there, readable in any editor. The on-disk format is written down in FORMAT.md.

Bring your old notes

Import from Bear, Obsidian, Apple Notes, Evernote exports, or plain Markdown. Inline tags become real tags, and Evernote attachments come along.

Edits from anywhere

Rename or move a note and the file moves on disk. Change a file in another editor and Skerry picks it up within about a second.

Search that keeps up

Full-text search runs on a local SQLite FTS5 index with prefix matching. The command palette jumps to any note by fuzzy title or path.

Tags, stars, and a real Trash

Tags with counts, starred and archived views, pinned notes, and a Trash that keeps deleted notes for thirty days.

Always at hand

Capture without opening the app, and let the rest of your Mac reach your notes.

Menu bar capture

Type a thought into the menu bar window and save it as a note without bringing the app forward.

Shortcuts and Siri

Create Note, Append to Note, and Search Notes are available as actions, so your notes join your automations.

On-device summaries and tags

On Macs with Apple Intelligence, Skerry can summarize a note and suggest tags with Apple's on-device model. Nothing leaves the Mac.

Insights

Library size, writing streaks, open tasks, and tag counts in one sheet.

Writing

The editor highlights Markdown as you type and hides the syntax away from the cursor, so prose reads clean while the markers stay editable.

Linked notes

Write [[note name]] to link a note. Following a link to a note that does not exist yet creates it, and a backlinks bar lists every note that points here.

Lists, tasks, and tables

Lists and quotes continue on Return. Task boxes toggle with a click and strike through when done. Skerry lines up table columns, inserts footnotes, and highlights the syntax inside code blocks.

Images in your folder

Paste an image and it lands in assets/ with a relative link, so the note still works outside Skerry.

Export anything

Export a note to Markdown, plain text, HTML, Rich Text, or PDF, or copy it as Markdown, HTML, or plain text.

Sync and backup on storage you own

Skerry runs no sync service of its own. You bring the storage.

Sync through WebDAV, S3, or a folder

Everything is sealed with your vault key before upload. Edits to different paragraphs merge, and real overlaps keep both versions for you to review.

Snapshots you can open

Write browsable folder snapshots to any location, or encrypted snapshots to WebDAV or S3. Automatic backup keeps the newest ten.

Version history

Browse earlier versions of a note with previews and restore any of them.

Or use what you already have

Because a library is a plain folder, iCloud Drive, Syncthing, rsync, or a NAS share all work too.

Why Skerry, next to Obsidian

Obsidian is excellent, and Skerry works the same way at heart: Markdown files in a folder you own. Where they differ is encryption and openness.

Sealed on disk

Obsidian notes sit on disk as readable text. In Skerry any note can be sealed, title and tags included, so a copied folder or a stolen backup reveals nothing.

Open source

Skerry is Apache 2.0, and the code and on-disk format are public. You can read exactly how your notes are protected.

Free, nothing to buy

There is no paid tier and no account. Sync goes through storage you already have.

Easy to try

Skerry imports Obsidian vaults, and your files stay plain Markdown, so leaving costs nothing.

Obsidian has a far larger plugin ecosystem, and Skerry is early. Skerry is for people who want their notes sealed and the code open.

Get Skerry

Skerry is free under the Apache 2.0 license, with no paid tier. It is early and changes often, so keep your own backups of anything that matters.
